# Folder & File Analyzer

Lightweight, open-source tool to analyze directory structures directly in your browser.

Open Source

Client-Side

🌟 Why Use This?
Privacy-first: Files stay on your machine (no server uploads).

Zero-install: Runs in any modern browser.

Transparent: Open-source MIT license—audit, modify, and share freely!

✨ Features

✅ Real-time file & folder counting  
✅ Drag-and-drop folder support  
✅ Animated progress indicators  
✅ Responsive design (desktop/mobile)  
✅ No tracking, ads, or bloat  

🛠 Tech Stack
Frontend	APIs Used
HTML5	File System Access
CSS3 (Flex/Grid)	webkitdirectory
JavaScript (ES6)	Drag-and-Drop API
